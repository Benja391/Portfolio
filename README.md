# Portfolio · Benjamín Bosch

Mi portfolio personal como desarrollador Full Stack: experiencia, proyectos destacados, tecnologías y contacto.

**🔗 Sitio:** https://mi-portfolio-benjamin-bosch.netlify.app/

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

## ✨ Características

- **Bilingüe (español / inglés)** con un botón para cambiar de idioma, que se recuerda en el navegador. El CV descargable cambia según el idioma.
- **Modo claro y oscuro**, que respeta la preferencia del sistema.
- **Diseño responsive** y animaciones suaves al hacer scroll, desactivadas con `prefers-reduced-motion`.
- **Accesible:** navegación con teclado, foco visible, enlace para saltar al contenido y textos alternativos.
- **Formulario de contacto** con FormSubmit, con protección contra spam (honeypot).
- **Sin frameworks ni dependencias:** HTML, CSS y JavaScript puro, en un solo archivo, con imágenes en WebP.

## 🗂️ Estructura

```
├── index.html     Sitio completo (estilos y scripts incluidos)
├── gracias.html   Página de confirmación del formulario
├── img/           Capturas de proyectos, foto e ícono
└── cv/            CV en español e inglés (PDF)
```

## ⚙️ Cómo verlo

Abrí `index.html` en el navegador o publicá la carpeta en cualquier hosting estático (Vercel, Netlify, GitHub Pages).
